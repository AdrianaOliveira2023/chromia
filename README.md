# Chromia

Ferramenta desenvolvida para extrair cores de fotografias e utilizá-las em identidades visuais, designs e projetos criativos.

## ✨ Funcionalidades

- Extração automática de cores
- Organização por luminosidade
- Limite inteligente de paleta
- Upload por clique ou arrastar e soltar
- Cópia rápida de códigos HEX
- Interface responsiva
- Glassmorphism + Neumorfismo

## 🖼️ Como funciona

O Chromia utiliza processamento de imagem via Canvas API para identificar cores predominantes e gerar paletas organizadas automaticamente.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
- Canvas API
